## Publish to Surge

From a machine logged in with `npx surge login`:

```sh
npx surge . parapsychology.surge.sh
```

Do not upload `video.MP4` or other unused source files. The live page only needs `index.html`, `styles.css`, `main.js`, `logo.png`, `hero.jpg`, and `favicon.svg`.
